# Të dhënat e kursit

Çdo dataset shënohet në slide si **“reale (burimi)”** ose **“sintetike”**.

## Reale — publike

| Dataset | Paketa | Java |
|---|---|---|
| Auto, Carseats, Default, Smarket | `ISLR2` | 5–9 |
| Advertising (`Advertising.csv`, ruhet në `02_data/`) | faqja statlearning.com — nuk është në ISLR2 | 5–6 |
| Boston | `MASS` | 5–8 |
| meuse (metale të rënda, lumi Meuse) | `sp` / `gstat` | 10–12 |

## Reale — shqiptare

INSTAT / Eurostat: shtohen vetëm kur ngarkohen skedarët origjinalë. Asnjë e dhënë nuk shpiket.
